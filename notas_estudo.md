# Desafio 1.1 – Projeto de Software

## 1. O que difere um Projeto de Software de um Script/Código isolado?

Um **Projeto de Software** é planejado, tem etapas, objetivos e busca atender às necessidades do cliente. Já um **Script** ou **Código isolado** é um programa simples, feito para resolver uma tarefa específica, sem precisar de todo esse planejamento.

---

## 2. Ciclo de Vida Básico

### Levantamento de Requisitos / Escopo

É a fase em que são definidos os objetivos e tudo o que o sistema deverá fazer.

### Desenvolvimento / Codificação

É quando os programadores criam o sistema e desenvolvem suas funcionalidades.

### Testes / Qualidade

Nessa etapa, o software é testado para encontrar e corrigir erros.

### Entrega / Implantação

É quando o sistema é entregue ao cliente e colocado para funcionar.

---

## 3. Por que definir um escopo fechado antes de programar?

Porque ajuda a evitar mudanças durante o desenvolvimento, reduz atrasos, evita retrabalho e facilita a entrega do software dentro do prazo.
